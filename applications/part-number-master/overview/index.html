Part Number Master

Overview​

The Part Number Master application is a foundational component of Maximo for Aviation that provides comprehensive management of part numbers, including Configuration-Managed (CM) part numbers. This application serves as the central repository for all part number definitions that are essential for aircraft configuration management, maintenance planning, and inventory control. The application is a modified version of the core Manage Item Master application with additional fields, tabs and related attributes to manage configuration-managed part numbers. Configuration-Managed Part Numbers represent the components that make up an aircraft or complex asset.

CM Part Numbers are used in Models and form part of the engineering reference data used to define an as-designed configuration. They establish the baseline for what components should be installed on an aircraft and provide the framework for tracking actual vs. designed configurations.

The Part Number Master is tightly integrated with the Model application, Master Task Cards, Operators Maintenance Program (OMP) and the Build Data Interpreter (BDI) to ensure configuration compliance and automated maintenance program management.

Key Capabilities:

  • Define and manage part numbers with comprehensive attributes
  • Establish configuration-managed part numbers for aircraft components
  • Define serial number formats and ranges for traceability
  • Create serial range usable-on codes (UOCs) for effectivity management
  • Display Master Task Cards for CM Parts (used for automated Task Card generation)
  • Support interchangeable parts and alternates
  • Manage part specifications, vendors, and storeroom locations
  • Track part assembly structures and relationships
  • Define ATA chapter codes for system organization
  • Support both hardware and software part number management

Serial Ranges for Part Number​

The Serial Ranges functionality allows for the definition of one or more Serial Range Usable on Codes (UOC) for each configuration-managed part number. Serial Range UOCs are a powerful feature that enables precise control over which serial numbers of a part are applicable to specific aircraft or configurations.

Purpose of Serial Range UOCs:

  • Define effectivity for specific serial number ranges
  • Support engineering changes that affect only certain serial numbers
  • Enable configuration rules based on component serial numbers
  • Track which part serial numbers are valid for specific aircraft

The Serial Range UOC is a unique value within the context of the CM Part Number that is used to identify a range of serial numbers. These UOCs are then referenced within specific configuration rules in the Model application to specify which positions or part numbers are valid for specific ranges of end item serial numbers.

Serial Range UOC Structure​

Each Serial Range UOC consists of two key components:

ComponentDescriptionExample
Serial Range Usable on CodeUnique identifier for the serial rangeUOC1, UOC2, EARLY_BUILD, LATE_BUILD
Serial Range ExpressionDefines the actual serial numbers included10001..19999, 20000..99999

Serial Range Expression Formats:

The Serial Range Expression can be defined using three different formats:

  1. Comma-Separated List of Serial Numbers

    • Format: Individual serial numbers separated by commas
    • Example: AA001, AA004, AA009
    • Use Case: When only specific, non-consecutive serial numbers are affected
    • Result: Only the explicitly listed serial numbers are included

  2. Range Notation Using Double Dots

    • Format: Start serial number, double dots (..), end serial number
    • Example: A001..A100
    • Use Case: When a continuous range of serial numbers is affected
    • Result: Includes A001, A002, A003, ... all the way to A100 inclusive
    • Note: The system automatically includes all serial numbers between start and end

  3. Combination of Both Formats

    • Format: Mix of individual serial numbers and ranges
    • Example: A001, A003, A006..A009
    • Use Case: When you need both specific serial numbers and ranges
    • Result: Includes A001, A003, A006, A007, A008, A009
    • Note: Provides maximum flexibility for complex effectivity scenarios

Serial Range Expression Examples:

ScenarioUOC CodeSerial Range ExpressionInterpretation

Creating Serial Range UOCs​

Step-by-Step Process:

  1. Navigate to the Serial Ranges tab in the Part Number Master
  2. Click Add Row to create a new serial range UOC
  3. Enter a unique Serial Range Usable on Code (e.g., UOC1, EARLY_BUILD)
  4. Define the Serial Range Expression using one of the three formats
  5. Validate the expression syntax
  6. Save the serial range UOC

Serial Range UOC codes must be unique within the context of a single part number. However, the same UOC code can be used across different part numbers with different serial range expressions.

Master Task Cards for Part Number​

The Master Task Cards for Part Number section displays all Master Task Cards that are related to the current configuration-managed part number. This relationship is fundamental to Maximo for Aviation's automated preventive maintenance generation capability and ensures that the correct maintenance tasks are created for each installed component.

Relationship Overview:

  • Master Task Cards are linked to part numbers in the Master Task Card application
  • The relationship is typically established when creating or editing Master Task Cards
  • Multiple Master Task Cards can be associated with a single part number
  • Each task card defines specific maintenance requirements for the component
  • The relationship drives automated PM generation through BDI validation

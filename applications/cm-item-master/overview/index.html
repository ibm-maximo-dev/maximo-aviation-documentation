CM Item Master (CM)

Overview​

The CM Item Master (CM) application provides the ability to define Configuration Managed Items.
CM Items represent the components which make up a complex asset and, when applied to an Asset, is the primary attribute that differentiates a configuration-managed asset from a standard Maximo Asset.
CM Items are used in a Model and form part of the engineering reference data used to define an as-designed configuration.

Serial Ranges for CM Item​

The Serial Ranges table allows for the definition of one or more Serial Range Usable on Codes (UOC). The Serial Range UOC is a unique value, within the context of the CM Item, that is used to identify a range of serial numbers. The Serial Range UOC is then referenced within specific configuration rules within a Model for example to specifiy which positions or CM Items are valid for a specific range of end item serial numbers.

Each Serial Range UOC has an associated Serial Range Expression which indicates the range of serial numbers to which the UOC is applied. The Serial Range Expression can be:

  • A comma separated list of serial numbers: AA001, AA004, AA009
  • A range of serial numbers indicated by a double dot notation: A001..A100
    Which indicates A001, A002, A003 etc all the way to A100 inclusive.
  • A combination of both: A001, A003, A006..A009
    Which indicates A001, A003, A006, A007, A008, A009

Master PMs for CM Item​

The Master PMs for CM Items table lists all those Master PMs which are related to the current CM Item. This relationship is normally established in the Master PM (CM) application.

The system will, by default, create PMs for all Assets with the specified CM Item automatically.

This occurs as part of the BDI validation of the Asset.

Application Actions​

Add to Item Master

The "Add to Item Master" action is used to create an Item Master record with the same name as the CM Item and establish a relationship between the two.
The Item Master record will be automatically set to be Rotating=Y.
When an Asset is created and the CM Item is specified the related Rotating Item Master record will also be applied to the Asset.

The relationship between CM Item and Item Master is normally one-to-one.

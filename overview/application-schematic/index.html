Maximo Aviation Application Schematic

Overview​

Maximo Aviation is a comprehensive aviation maintenance management solution built on IBM Maximo that provides end-to-end capabilities for managing aircraft fleets, maintenance programs, technical records, and regulatory compliance. This document provides implementation consultants with a detailed understanding of the application architecture, module relationships, and data flows within the system.

The schematic above illustrates a subset of the main components of the Maximo Aviation application landscape, showing how different modules interact to support aviation maintenance operations. Applications are color-coded by functional area for easy identification.

Application Architecture​

Maximo Aviation is organized into four primary functional areas, each represented by a distinct color in the schematic:

ColorFunctional AreaPurpose
PurpleConfiguration & Master DataFoundation data that defines the structure and standards for the entire system
BlueCore OperationsDay-to-day operational applications for asset management, maintenance planning, and execution
GreenQuality ManagementApplications supporting quality assurance, audits, and continuous improvement
PinkCustomer ManagementCommercial applications for managing customer relationships, billing, and service agreements

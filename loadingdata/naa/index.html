New Asset Assemblies

Overview​

The New Asset Assemblies (NAA) application enables a user to create a CM managed asset hierarchy from a Model. This page gives instructions, and an example, on how New Asset Assemblies records can be loaded through the Maximo Integration Framework (MIF).

This includes the top level asset record and related meters and also the sub assembly (child) assets and their related meters.

In order to facilitate the loading of a New Asset Assemblies record, an MXLoader Excel template is provided in the link below. The example provided enables the creation of a Rapid Transit Metro Train (RTMT) type Asset and it's sub assembly asset hierarchy:

Rapid Transit Metro Train - New Asset Assemblies Example​

Download RTMT New Asset Assemblies - MXLoader

An explanation of the individual data elements and worksheets contained within the MXLoader file is described below. The worksheets are ordered in the necessary way to support the loading of the New Asset Assemblies data.

New Asset​

The New Asset worksheet is used to create the main New Asset Assemblies record (PLUSANEWASSET). Data on this record will ultimately be used to create an ASSET record in Maximo. The record contains the asset number, serial number, registration (if specified as required in the associated Model) and other CM Related data eg, CM Item, Model, Variant etc.

New Asset Meters​

The New Asset Meters worksheet is used to specifiy the data that will be used to create the Asset Meter records for the top level asset. These are limited to CONTINUOUS type Meters. Meters can also be automatically added to the Asset by way of a Meter Group which is linked to the Item Master record associated with the CM Item.

ubassemblies​

The Subassemblies worksheet contains the information required to create the asset assembly hiearchy below the top level asset. Each sub assembly asset needs to specify it's parent asset, CM Item and serial number. To indentify the position in the Model to which the asset corresponds the Label and Position can be specified if the combination of these values uniquely identifies the position within the model. If it does not it is preferable to specify the build identifier (PLUSANEWSUB.BUILDID). This is the identifier of the position within the Model (PLUSACMBUILD.PLUSACMBUILDID).

Note that the sub assemblies can be generated through the UI and then queried using MXLoader. The sheet can then be updated to specify the serial number, CM Item, Install Date etc of each subassembly asset before it is then sent back in Maximo.

Subassembly Meters​

The Subassembly Meters worksheet specifies the Continuous meters records to create against each sub assembly. There is one line per asset per meter. The Anchor Count should reflect the life of the asset at the Anchor Date. The Since New value should be set to the life of the asset at the time of asset creation. This will be used to create a METERREADING record of type ACTUAL with the Since New Value and a Reading Date = to the system date/time at asset creation.

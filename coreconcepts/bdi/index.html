Build Data Intepreter (BDI)

Overview​

The Build Data Interpreter (BDI) is a central and critical component of the Maximo Asset Configuration Manage solution.

It is deployed automatically, as a separate application within the Manage namespace, when ACM is is activated as a component of Manage.

It is responsible for verifying and ensuring the compliance of operational modifications to configuration-managed (CM) assets in accordance with the reference data and configuration rules defined within an associated model and its related maintenance plans.

The BDI can be executed manually for a specific CM managed asset hierarchy, using the BDI Status dialog within the Assets (CM) application. The BDI also validates CM assets in the asynchronously in background in one of two ways:

  • On a time-based schedule (by default every 3 hours)
  • On an adhoc bases when when particular transactions, which may effect the configuration status of the asset, are executed by a user of the system or via an integration process.

BDI Responsibilities​

  • Examines configuration-managed assets on a position-by-position basis, ascertaining their adherence to the configuration rules defined in the associated Model.
  • Provides a comprehensive status for an asset, which can be viewed in the BDI Status dialog, and highlights non-conformity by reporting problem codes with corresponding details.
  • Assesses the maintenance program for an asset and triggers the creation of work orders at a pre-determined alert threshold.

An indepth description of the BDI, it's operation and configuration is provided in a dedicated section. Thes Assets (CM) application topic also goes into detail on how the BDI status for an Asset is reported.
